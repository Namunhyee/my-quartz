# 28번

## 발문

Biomolecular condensate 형성에서 multivalency의 역할로 가장 적절한 것은?

## 선지

- ① 여러 결합 부위가 각각 더 강하게 결합하여, 단백질 복합체를 안정적이고 고정된 구조로 만든다.
- ② 여러 결합 부위가 동시에 약하게 결합하여, 분자들이 모인 동적인 그물망 구조(liquid-like phase)를 형성한다.
- ③ 여러 결합 부위가 막 단백질과 결합하여, 응집체 주위에 물리적 경계를 형성한다.
- ④ 여러 결합 부위가 효소 반응을 억제하여, 응집체 내부의 반응 속도를 낮춘다.
- ⑤ 여러 결합 부위가 단백질 접힘을 안정화하여, 잘못 접힌 단백질의 축적을 막는다.
